# API

Request and response contracts for the external dashboard/app.

Modules:

- `device/`: robot discovery, firmware status and binding.
- `ops/`: health, logs, metrics and diagnostics.
- `vision/`: camera snapshot, observation and future recognition contracts.
- `agent/`: conversation, local intent and LLM/TTS status.
- `agenda/`: time, timers, reminders and alarms.
